# PRJ381_Fly-By-Wire
The 3rd year project of Group 6 at Belgium Campus iTversity during the 2026 academic year.

# Requirements
1. Python 3.13.x or lower
2. Pygame
3. Pyserial

## On Windows
1. Install python 3.13.x or lower
2. In VSCode terminal:
```bash
pip install pygame pyserial
```
3. Run `main.py` from VSCode (not yet complete)

## On Raspberry Pi
**Do NOT run VSCode on the pi. It's far too slow and will probably crash**
1. In terminal:
```bash
cd ~ && sudo apt install python3-full python3-pygame python3-pyserial
```
2. In terminal inside this folder: (not yet complete)
```bash
python main.py
```
